# Proposals

A job post is a listing you create to tell freelancers what you need. Describe your project, the skills required, scope, and budget so they can send tailored proposals.

This is a sample flow for listing and viewing client proposals for a job posting using the GraphQL API.

**Workflow: Working with Proposals as a client**
1. **List proposals** — call [`clientProposals`](../../queries/clientProposals.md) (query): List proposals to jobs
2. **View proposal** — call [`clientProposal`](../../queries/clientProposal.md) (query): View job proposal details
3. **Message client proposal** — call [`messageClientProposal`](../../mutations/messageClientProposal.md) (mutation): Message a client proposal

This is a sample flow for listing and viewing freelancer proposals for a job posting using the GraphQL API.

**Workflow: Working with Proposals as a freelancer**
1. **List proposals** — call [`vendorProposals`](../../queries/vendorProposals.md) (query): List proposals
