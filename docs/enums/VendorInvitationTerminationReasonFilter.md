# `VendorInvitationTerminationReasonFilter` (enum)

## Description

The values represents the reason of invitation termination, used in searching for invitation

## Values

| Values | Description |
|---|---|
| `All` | All termination reasons |
| `Declined` | Invitation was declined by the vendor |
| `Withdrawn` | Invitation was withdrawn by the client |
| `Archived` | Invitation was archived |
| `Accepted` | Invitation was accepted by the vendor |
| `PendingOnHold` | Invitation is pending and on hold |
